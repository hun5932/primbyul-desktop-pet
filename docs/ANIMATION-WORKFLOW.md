# 애니메이션 자산 작업

## 원칙

동작은 창이나 사진 전체의 확대·축소가 아니라 서로 다른 신체 자세의
키프레임으로 보여야 합니다. 같은 행동 안에서는 프림의 체형과 표시 크기를
고정하고 발 또는 몸통 기준점을 맞춥니다.

## 폴더 계약

입력:

```text
assets/source-keyframes/
├─ adult/
│  ├─ idle/key-0.png ... key-3.png
│  └─ ...
└─ puppy/
```

출력:

```text
assets/frames/<adult|puppy>/<action>/<0|1|2|3>.png
```

필수 행동:

- `idle`
- `run`
- `wag`
- `play`
- `watch`
- `sit`

`run-left`는 도구가 `run`을 수평 반전해 자동 생성합니다.

## 이미지 규격

- RGBA PNG
- 최종 크기 512×512
- 배경 완전 투명
- 네 방향 테두리의 알파값 0
- 동작별 네 장
- 얼굴, 털색, 코, 눈, 혀, 체형의 정체성 일치
- 그림자·바닥·목줄·문자·프레임 번호 없음

## 정체성 기준

성견:

- 실제 프림의 넓고 둥근 얼굴
- 짧고 묵직한 주둥이
- 큰 검은 코
- 부드럽고 약간 가늘게 보이는 눈
- 넓게 웃는 입과 분홍 혀
- 풍성한 가슴털과 큰 꼬리

퍼피:

- 머리 비율이 크고 다리가 짧음
- 짧은 주둥이
- 폭신하고 둥근 퍼피 털
- 성견과 같은 코·눈·미소 정체성

`assets/reference-photos`는 새 프레임 생성 시 비교 기준이며 실행파일에는
포함되지 않습니다.

## 정렬 도구

```powershell
python -m pip install -r requirements-assets.txt
python tools\build_assets.py
```

동작별 처리:

- `idle`, `wag`, `watch`: 발바닥 선 기준
- `sit`: 몸통 중앙과 바닥선 기준
- `run`, `play`: 공통 중심과 공통 배율
- `play`: 셀 잘림 방지를 위해 최대 90% 공통 배율

작은 누끼 파편은 본체에서 멀리 떨어진 경우 제거합니다. 저알파 누끼 테두리도
본체 안전 영역 밖에서는 정리합니다.

## 눈 깜빡임 계약

`idle`과 `sit`:

- key 0: 눈 뜸
- key 1: 반쯤 감음
- key 2: 완전히 감음
- key 3: 눈 뜬 변형 또는 안정 프레임

코드가 0→1→2→1→0으로 재생합니다.

## 프레임을 새로 만들 때 검수

1. 100% 크기로 얼굴 정체성 비교
2. 회색 배경에서 누끼 경계 확인
3. 네 프레임을 빠르게 넘겨 머리·발의 불필요한 좌우 흔들림 확인
4. 220px 실제 표시 크기로 동작 가독성 확인
5. 플레이·달리기에서 귀·꼬리·발 잘림 확인
6. 성견과 퍼피가 명확히 구별되는지 확인
7. `validate_source.py` 통과

## 새 행동 추가

새 행동은 이미지 폴더만 추가해서 끝나지 않습니다.

1. 두 모습의 키프레임 네 장 추가
2. `build_assets.py`의 `STATES` 추가
3. Windows `STATE_*`, sequence, `k_states` 추가
4. Windows RC에 성견·퍼피 리소스 ID 추가
5. macOS `STATE_*`, directory, sequence, delay, loops 추가
6. 두 메뉴에 action 추가
7. 자동 선택 확률에 포함할지 결정
8. 소스 검증의 예상 프레임/리소스 수 갱신
9. 두 플랫폼에서 수동 동작과 자동 복귀 확인
