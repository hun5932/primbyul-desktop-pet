# Primbyul v1.5 macOS 실행

1. ZIP 압축을 풉니다.
2. `Primbyul.app`을 Applications 폴더로 옮깁니다.
3. 처음 한 번은 앱을 Control-클릭하고 `열기`를 선택합니다.

Apple Silicon과 Intel을 모두 포함한 Universal 앱입니다.

메뉴 막대의 프림별 얼굴 아이콘에서 모습, 동작, 크기, 항상 위, 클릭 통과,
숨기기, 자동 실행, 제거를 조절합니다.

로그인 자동 실행은 macOS 13 이상에서 지원합니다. 승인이 필요하면 시스템
설정 → 일반 → 로그인 항목에서 Primbyul을 허용합니다.

이 개발 빌드는 Apple Developer ID 서명·공증이 없을 수 있습니다.
